## ⚠️ SOBRE A GAVETA

**Por que não funciona?**
- Vercel usa HTTPS
- Impressora usa HTTP
- Navegador bloqueia por segurança

**Soluções:**
1. Aceitar limitação (temporário)
2. Usar impressora USB (recomendado)
3. Criar app desktop (melhor)
